# Perseverance — Architecture & Module Contracts

Perseverance is a desktop (Electron) Photoshop-style editor specialized for **stylized Roblox
thumbnails, icons and GFX** (gothic paper posters, halftone comic looks, noir newspaper
collages, crimson film/smoke looks, posterized/cel-shaded Roblox characters…).

Stack: Electron 44 · Vite 7 · React 19 · TypeScript 5.9 (strict) · zustand 5 + immer · Canvas 2D
(Chromium-only APIs allowed: `ctx.filter`, `ctx.letterSpacing`, `roundRect`, `Path2D(svg)`,
`OffscreenCanvas`, `EyeDropper`, `queryLocalFonts`) · three.js (Roblox Pose Studio) · ag-psd · lucide-react icons.

**Everything must work offline** (fonts/assets bundled or procedurally generated). No network
calls except the optional Roblox avatar fetch.

---

## 1. Core principles

1. **Document = immutable JSON** (`src/core/types.ts`). Pixels live in the `bitmaps` store
   (`src/core/bitmaps.ts`), referenced by id. Never put canvases/ImageData into the document.
2. **All undoable changes go through the editor store** (`src/state/editor.ts`):
   - `useEditor.getState().commit(label, draft => {...}, opts?)` — one history step.
   - Live drags: call `preview(recipe)` on every move, then `commit(label)` (no recipe) on release,
     or `cancelPreview()`.
   - Pixel edits: `const patch = bitmaps.edit(bitmapId, ctx => ..., rect?)` then
     `commit(label, recipe?, { patches: [patch] })`. For brush strokes, record the before-image of
     the dirty rect at stroke start, paint live into the bitmap canvas (call `bitmaps.touch(id)` +
     `viewport.requestRender()` while painting), and build the BitmapPatch on release.
   - Helpers: `addLayer`, `updateLayer`, `removeLayers`, `moveLayer`, `groupLayers`, `ungroupLayer`,
     `setActiveLayer`, `setSelectedLayers`, `setEditTarget`, `undo`, `redo`, `jumpToHistory`.
   - Non-reactive accessors: `activeSession()`, `activeDoc()`, `activeLayer()`, `toolOptions(id, defaults)`.
   - React hooks: `useActiveSession()`, `useActiveDoc()`, `useActiveLayer()`, `useToolOptions(id, defaults)`,
     or `useEditor(selector)`.
3. **Extension through registries** (`src/registry/index.ts`): tools, panels, commands, filters,
   effects, assets, shapePresets, gradientPresets, palettes, brushPresets, looks, templates,
   docPresets, fonts, viewOverlays, statusItems, propertiesSections. Each module registers its
   definitions in its own `index.ts` (imported by `src/features.ts`). **Do not edit other modules'
   files**; if you need something from another module, use the contracts below.
4. **Layer transform**: `(x, y)` = top-left of the unrotated local box; rotation/scale pivot on the
   box center. Use `transformMatrix(t, w, h)` / `transformedCorners` / `transformedBounds` from
   `src/core/geometry.ts`. Local box size: `getLayerSize(layer)` from the compositor.
5. **Layer order**: `doc.rootIds` and `group.childIds` are **bottom → top**. The layers panel shows
   them reversed (use `displayList(doc)` from `src/core/document.ts`).
6. **Params**: filters/effects/assets/looks declare `ParamDef[]`; the UI is generated by
   `<ParamEditor defs values onChange onCommit/>`. Always merge with defaults via
   `resolveParams(def, params)` (src/filters/engine.ts) — never assume a key is present.
7. **Performance**: documents are typically 1920×1080 or 1024×1024. Keep per-pixel loops tight
   (typed arrays, no per-pixel allocations/closures). Prefer GPU canvas ops (`ctx.filter = 'blur()'`,
   composite operations) where possible. Cache renders keyed by immutable object identity +
   `bitmaps.version(id)`.
8. **Style**: dark, compact, monochrome pro-editor UI like Photoshop/Photopea (see §6). Use the
   CSS tokens in `src/styles/theme.css` and the shared controls in `src/ui/controls`. Icons from
   `lucide-react` (v1.x — verify names exist: `node -e "console.log(!!require('lucide-react').Brush)"`).
   Module-specific CSS goes in a `.css` file next to your components, imported by them, with
   class names prefixed by your module (e.g. `.layers-row`, `.shell-menubar`).
